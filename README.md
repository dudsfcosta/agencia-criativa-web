# 🎓 EBAC — Módulo 11: Agência Criativa Web

## 📖 Sobre

Página única com as seções clássicas de um site institucional:

- **Hero** — "Criamos experiências digitais incríveis"
- **Sobre Nós** e **Nossos Serviços**
- Depoimentos de clientes
- Formulário de contato

## 🚀 Como visualizar

Site estático — abra o `index.html` no navegador.

## 🛠️ Tecnologias

HTML5 • CSS3

## 💡 O que aprendi

- Estruturação de uma landing page completa em HTML semântico
- Organização de estilos em folha CSS dedicada (`estilos.css`)
- Seções recorrentes de sites reais: hero, serviços, depoimentos e contato
